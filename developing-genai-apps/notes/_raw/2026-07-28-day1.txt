에이전트 구성요소
프로덕션 에이전트를 이루는 6가지 핵심 요소

프롬프트 → 컨텍스트 → 하네스 엔지니어링 지금은 하네스(모델 + 하네스)
하네스도 결국엔 도구들

Agent
목표를 자율적으로 달성하는 AI 시스템
Model
컨텍스트를 읽고 다음 행동을 결정하는 추론 엔진 — 에이전트의 두뇌
Tools
외부 시스템과 상호작용하는 인터페이스 — API, DB, 파일
Memory
대화 이력 + 장기 기억 — 컨텍스트 축적
Guardrails
행동 제한 — 금지 도구, 비용 한도, PII 차단
Context
시스템 프롬프트 + 대화 + 도구 결과 → 여기에 RAG도 들어갈 수 있음
Orchestration
ReAct/ReWoo 루프 제어 + 멀티스텝 관리
ㄴ 모델 빼고 나머지가 다 하네스임

1
AI Assistant
사람이 실행
사람이 주도 — AI는 답변과 제안까지, 실행은 사람 (챗봇 · Copilot 인라인 제안)
2
AI Agent
AI가 실행
목표를 위임 — 도구를 호출하고 결과를 판단하며 목표 달성까지 실행하는 단일 에이전트
권한 위임은 여기부터 — 고위험 동작 앞에는 승인 게이트(HITL)
3
Agentic AI
AI가 계획·실행
시스템 수준 자율 — 멀티 에이전트 협업 · 멀티데이 태스크 · 자기 검증
