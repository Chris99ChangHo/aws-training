시리즈 2: Strands 에이전트
시리즈 개요
Strands Agents SDK로 강남 다이닝 컨시어지를 3단계로 완성합니다. @tool로 식당 검색·메뉴 도구를 만들고 MCP 서버를 연결한 에이전트에서 출발해, 멀티턴 대화 유지와 세션 저장·복원을 붙이고, 도구·대화·MCP를 모두 합친 Streamlit 앱으로 마무리합니다. 여기서 익힌 도구 정의·에이전트 구성은 이후 대부분의 에이전트 시리즈가 전제하는 기본기입니다.

Prompt

tools.py를 작성해 주세요 — 강남 식당 도구입니다.
1. 식당 5곳(트라토리아 벨라: 이탈리안·강남역, 스시 오마카세 하루: 일식·강남역, 한우명가: 한식·역삼역, 르 비스트로: 프렌치·압구정역, 매콤한 마라: 중식·강남역)을 name/cuisine/location/price_range/rating/menu 딕셔너리 리스트로 정의해 주세요.
2. @tool search_restaurants(location, cuisine)와 @tool get_menu(restaurant_name)를 만들어 주세요 — 타입 힌트와 docstring 필수입니다.
완료 기준: 직접 호출 시 조건에 맞는 식당 목록/대표 메뉴·가격 문자열이 반환되면 성공입니다.
Prompt

mcp_server.py를 작성해 주세요 — 예약 MCP 서버입니다.
1. FastMCP("reservation-server")로 서버를 만들고 @mcp.tool() check_reservations(restaurant_name, date, time, party_size)를 정의해 주세요 — 예약 가능 여부와 남은 좌석을 반환합니다.
2. mcp.run(transport="stdio")로 실행되게 해 주세요.
완료 기준: python mcp_server.py가 stdio 서버로 기동되면 성공입니다.
Prompt

agent.py를 작성해 주세요 — @tool + MCP 통합 에이전트입니다.
1. MCPClient(lambda: stdio_client(StdioServerParameters(command="python", args=["mcp_server.py"])))로 예약 서버를 연결해 주세요.
2. Agent의 tools에 search_restaurants, get_menu, reservation_mcp를 함께 넣어 주세요 — 모델은 us.anthropic.claude-sonnet-4-6입니다.
3. "내일 저녁 7시에 2명이 갈 만한 강남역 이탈리안 식당 찾고, 예약 가능한지 확인해 주세요"로 테스트해 주세요.
완료 기준: 검색 도구와 예약 조회 도구가 순차 자동 선택되어 예약 가능한 추천이 반환되면 성공입니다.
Prompt

app.py를 작성해 주세요 — 통합 에이전트의 최소 확인용 Streamlit 미니 챗입니다.
1. agent.py의 통합 에이전트 구성을 재사용해 주세요 — 새 에이전트 로직을 만들지 않습니다.
2. st.chat_input으로 질의를 받아 에이전트 응답을 st.chat_message로 표시해 주세요 — 입력창과 응답 표시만 두고, 사이드바 도구 로그·식당 카드·멀티턴은 넣지 않습니다.
3. streamlit run app.py로 띄우고 브라우저에서 "내일 저녁에 예약 가능한 강남역 이탈리안 식당 추천해 주세요"를 입력해 주세요.
완료 기준: 브라우저 챗 화면에 검색·예약 조회 도구의 결과가 반영된 추천 응답이 표시되면 성공입니다.

도전 과제 방향
스트리밍 응답: 동기 호출 대신 agent.stream_async(prompt)의 비동기 이벤트에서 텍스트 델타를 골라 st.write_stream으로 연결합니다.
추천 리스트 PDF 내보내기: 추천 카드에 표시한 식당 데이터를 누적해 두고 PDF 생성 라이브러리로 변환한 뒤 st.download_button으로 제공합니다.
평점 표시: restaurant_tools.py의 내장 데이터에 이미 rating 필드가 있습니다 — render_cards에서 별점(⭐)으로 환산해 캡션에 추가합니다.

핵심 포인트
create_agent() 팩토리로 모듈화하면 Streamlit·CLI·테스트에서 동일한 에이전트 구성을 재사용합니다
@st.cache_resource로 에이전트를 1회만 생성합니다 — rerun마다 재생성하면 느려지고 세션·MCP 연결이 반복됩니다
도구 호출 로그는 callback_handler의 current_tool_use 이벤트에서 수집하고 toolUseId로 중복 제거합니다
FileSessionManager(프로세스 재시작 간)와 st.session_state(rerun 간) 조합으로 대화가 유지됩니다

관련 실습
Strands Agents SDK 기초 — 기본 에이전트, @tool, Structured Output, Streamlit
Strands MCP 클라이언트 — MCPClient stdio/HTTP 연결, 도구 자동 발견, 혼합 사용
Conversation Management — 멀티턴 대화 컨텍스트 관리와 세션 유지

도전 과제
스트리밍 응답: 에이전트 응답을 글자 단위로 스트리밍 표시해보세요.
추천 리스트 PDF 내보내기: 추천 식당 리스트를 PDF로 다운로드할 수 있게 해보세요.
평점 표시: 식당 카드에 별점(⭐)을 표시해보세요.
